# 湯めぐり帖 — 公開と共有の手順

お父さんの退院後に行く「記念日の宿・一生に一度の宿」を、家族みんなで選ぶアプリです。
日常使いの日帰り温泉は載せていません。由緒と格のある十二軒だけを収めています。
`index.html` と `img/` フォルダだけで動きます。ビルドも npm も不要です。

```
yumeguri/
  index.html      ← アプリ本体（1ファイル）
  img/*.jpg       ← 写真9枚（ウィキメディア・コモンズの自由ライセンス）
  README.md
```

## 手順2：家族で共有できるようにする（Firebase・5分）

手順1のままだと、お父さんが書いた★をお母さんの端末では見られません。
共有したい場合だけ、以下をやってください。

1. https://console.firebase.google.com/ で「プロジェクトを追加」
   （Google Analytics は「有効にしない」でOK）
2. 左メニュー **Firestore Database** →「データベースを作成」
   → ロケーションは `asia-northeast1（東京）` → **テストモードで開始**
3. 歯車アイコン → **プロジェクトの設定** → 下部の「マイアプリ」で **`</>`（ウェブ）** を選択
   → アプリ名は何でもOK → 表示される `firebaseConfig = { ... }` の中身をコピー
4. `index.html` の上のほうにある `var FIREBASE_CONFIG = { ... };` に貼り付けて、コメントの `//` を外す

```js
var FIREBASE_CONFIG = {
  apiKey: "AIza...",
  authDomain: "xxxx.firebaseapp.com",
  projectId: "xxxx",
  storageBucket: "xxxx.appspot.com",
  messagingSenderId: "000000000000",
  appId: "1:0000:web:xxxx"
};
```

5. push すると、画面下の表示が「家族みんなで共有中です」に変わります。

### 閲覧を家族だけに限る

テストモードは30日で書き込みが止まり、その間はURLを知る人なら誰でも書けます。
URLを家族にしか伝えなければ実用上は困りませんが、気になる場合は
Firestore の「ルール」を次のようにして、期限だけ延ばしてください。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.time < timestamp.date(2027, 12, 31);
    }
  }
}
```

無料枠（1日あたり読み取り5万・書き込み2万）に対して、家族数人の利用は桁違いに小さいので
費用は発生しません。

### 写真について
写真はすべて **ウィキメディア・コモンズの自由ライセンス**（CC0 / CC BY / CC BY-SA / パブリックドメイン）
のみ。宿の公式サイトの写真は使っていません。撮影者とライセンスを画面に表示しています。

**「宿の写真」と「周辺の風景」を写真の左上で区別しています。**
宿そのものの写真があるのは4軒（積善館「元禄の湯」／法師温泉 長寿館の玄関／宝川温泉の露天／
富士屋ホテル本館）。5軒は周辺の風景、3軒（仙寿庵・大黒屋・枇杷）は写真なしです。
写真の無い宿は、詳細画面の「写真をもっと見る」（Google画像検索）からご覧ください。

各宿の詳細画面には次のリンクが付きます。
| リンク | 中身 |
|---|---|
| 写真をもっと見る | Google 画像検索 |
| 地図・行き方を見る | Google マップ |
| ウィキペディアで読む | 記事があるものだけ（存在を確認済み） |
| 公式サイト・料金を調べる | Google 検索 |

### 絞り込み
- **客室露天・貸切あり** — 人目を気にせず入れる宿に絞る（該当4軒：仙寿庵・強羅花壇・あさば・枇杷）
- **坂・段差が少ない** — お母さんの膝を考えて「坂・階段が多い」を除く
- **日帰り入浴もできる** — まず下見に行ける宿（該当4軒）
- **距離** — レモンハウス（鴻巣市）からの直線距離で 100 / 120km 以内

### 各施設に記録できること
- 家族ひとりずつの **★1〜5 と ひとこと**（あとから直せます）
- **ストーマ受け入れの確認ぐあい**（未確認 / 電話でOK / 実際に入れた）＋メモ
  → 電話で確かめた人が更新すると、全員の画面に反映されます
- **電話で聞くことリスト** — そのまま読み上げられる質問7つ

## データについての注意

- 施設の情報（貸切風呂の有無・坂・泉質）は**下調べです。検証済みの事実ではありません。**
  営業時間・料金・休館日は載せていません（変わるため）。行く前に必ず電話で確認してください。
- 「貸切・個室風呂あり」が付いていない施設も、実際にはある場合があります。あくまで出発点です。
- 所要時間は直線距離からの推定で、実際の道のりとは異なります。
- 「客室露天・貸切あり」を付けた4軒以外にも、実際には貸切風呂がある宿はあります。
  確度の高いものだけに印を付けており、残りは「要確認」です。
- 創業年・文化財指定・ルレ・エ・シャトー加盟などは広く知られた事実ですが、
  **現在の営業状況・改装・客室構成は変わります。** 予約時にご確認ください。
- 厚生労働省と各都道府県は「ストーマ装具を正しく装着した状態での公衆浴場の利用は
  衛生上の問題はない」という趣旨の通知を出しています。断られる理由は本来ありません。

## 候補を足す・直すには

`index.html` の `var SPOTS = [ ... ]` に1件足すだけです。

```js
{ id:"ユニークなID", name:"施設名", area:"都道府県＋市町村", lat:36.0, lng:139.5,
  stay:"day",            // day=日帰り / stay=泊まり / both=どちらも
  kashikiri:"unknown",   // yes=貸切・個室あり / unknown=要確認
  terrain:"flat",        // flat=ほぼ平坦 / mild=多少の坂 / hilly=坂・階段が多い
  spring:"泉質",
  why:"この湯を薦める理由を1〜3文で",
  caution:"注意点があれば（無ければこの行ごと消す）",
  wiki:"ウィキペディアの記事名（無ければこの行ごと消す）",
  photos:[{f:"ファイル名.jpg", cap:"何の写真か"}] }   // img/ に置く。無ければこの行ごと消す
```

緯度経度は Google マップで施設を右クリックすると出ます。距離と所要時間は自動計算です。
